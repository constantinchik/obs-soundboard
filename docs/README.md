# Documentation

Extra documentation for OBS Soundboard lives here.

## Assets

Images used by the project README and these docs go in [`assets/`](assets/).

- Use lowercase, hyphenated file names, e.g. `soundboard-dock.png`.
- Prefer PNG for screenshots and GIF/WebP for short animations.
- Keep files reasonably small (crop to the relevant UI, aim for under ~500 KB).

Reference them with a path relative to the file you're editing:

- From the root `README.md`: `![Alt text](docs/assets/soundboard-dock.png)`
- From a file in `docs/`: `![Alt text](assets/soundboard-dock.png)`
