# OBS Soundboard

OBS plugin that adds a soundboard dock.

## Features

- Add, edit, and remove sounds with drag-and-drop support
- Hotkey support for triggering sounds
- Per-sound volume and loop settings
- Grid or list view modes
- **System Audio Output**: Play sounds through your system's default audio output in addition to the OBS virtual audio track. This allows you to hear the sounds locally while streaming/recording. The system audio volume syncs with the OBS mixer slider in real-time.
